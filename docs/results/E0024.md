# E0024: oracle ceiling on the 0.931 anchor

E0024 combines E0023's frozen leaderboard-verified 0.931 configuration with the E0022 GT-aware oracle fork-repair diagnostic. It runs independently to measure the recoverable division headroom and adjusted-edge cost directly on the production anchor.

This run is diagnostic only and cannot produce a valid competition submission.

## Result

The frozen anchor reproduced E0023 exactly at `0.926608`: adjusted edge Jaccard `0.914108`, division Jaccard `0.125000`, and `4 TP / 14 FP / 14 FN` divisions.

Oracle rewiring reached `0.963285`: adjusted edge Jaccard `0.916410`, division Jaccard `0.468750`, and `15 TP / 14 FP / 3 FN`. Eleven missed divisions were repaired, four were already true positives, two lacked role evidence, and one lacked consecutive fork geometry.

This confirms the greater-than-0.95 ceiling directly on the leaderboard-verified production anchor. Correct rewiring also improves adjusted edge accuracy, so the deployable objective is a high-precision fork ranker rather than a broad increase in predicted divisions.
