# E0043: candidate-domain hard-negative fine-tuning

E0043 starts from each E0039 embryo-held-out raw temporal-crop model and adapts it using detector-centered proposals from the opposite embryo. Hard negatives are mined by the legal fold model itself; annotated training positives are retained as a stabilizer. Evaluation remains on the complete dense candidate pool of the held-out embryo.

Configuration: binary cross-entropy, 1,024 top hard negatives and 512 reservoir-sampled negatives per fold, 12 fine-tuning epochs, learning rate `2e-4`.

Status: running on Kaggle. No graph mutation is performed.
