# E0034: oracle ceiling on the 0.933 anchor

E0034 combines E0033's frozen 0.933 configuration with the GT-aware oracle fork-repair audit. It measures division-repair headroom directly on the strongest known leaderboard configuration.

This run is diagnostic only and cannot produce a competition submission because its rewiring stage uses ground truth.

## Result

The 0.933 anchor reproduced E0033 at `0.936854`: adjusted edge Jaccard `0.918336`, division Jaccard `0.185185`, and division counts `5 TP / 9 FP / 13 FN`.

Oracle rewiring reached `0.972017`: adjusted edge Jaccard `0.920166`, division Jaccard `0.518519`, and `14 TP / 9 FP / 4 FN`. Nine missed divisions were repaired, five were already true positives, three lacked role evidence, and one lacked consecutive fork geometry.

Correct rewiring therefore provides `+0.035163` local combined headroom on the stronger anchor and improves edge accuracy rather than trading it away. Fourteen of 18 annotated divisions are repairable from current detections.
