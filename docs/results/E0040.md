# E0040: temporal-difference 3D division classifier

E0040 shares E0039's embryo-held-out crop dataset and CNN, adding explicit current-minus-previous and next-minus-current channels. This tests whether temporal changes around mitosis generalize better than raw three-frame appearance alone.

The run is diagnostic and does not alter the tracking graph.

## Result

Positive but weaker than E0039. The same 6,921-example, 151-positive census achieved mean held-out average precision `0.2971` and ROC AUC `0.7928`. The strictest audited threshold retained `6 TP / 1 FP`, compared with E0039's `7 TP / 0 FP`.

Explicit difference channels do not improve generalization, so raw three-frame crops are selected for candidate transfer.
