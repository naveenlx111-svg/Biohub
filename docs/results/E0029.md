# E0029: parent-event image ranker

E0029 keeps E0028's embryo-held-out top daughter pair for every proposed parent and adds parent-level evidence from the raw 3D image, adjacent timepoints, daughter patches, and the auxiliary DeepCenter response. A second embryo-held-out classifier tests whether these features can distinguish actual dividing parents from ordinary cells.

This remains diagnostic and does not mutate the graph. A usable result requires a large improvement in global average precision and at least one threshold with a small number of false parent events. If successful, the selected threshold and E0028 pair choice will be integrated into a submission-producing E0030 run.

## Result

Rejected and structurally invalid for final inference. Only 72,406 parent candidates and nine positives survived the join, rather than E0028's 118,779 parents and 16 positives. The cause is that E0029 reran inference and then joined E0028 output using internal node IDs, which are not stable across independent runs.

On the surviving subset, mean embryo-held-out average precision was `0.000219` and mean ROC AUC was `0.5479`. The best audited threshold retained one true candidate with at least 3,620 false candidates. These features did not establish useful parent-event separation, and the cross-run join must not be reused.
