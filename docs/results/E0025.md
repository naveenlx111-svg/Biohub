# E0025: conservative division veto on the 0.931 anchor

E0025 freezes the leaderboard-verified 0.931 pipeline and changes one executable setting: `BIOHUB_DEEPCENTER_SAFE_DIV_VETO` from `0` to `1`.

E0023 found the same four division true positives as SDW75 but 14 false positives instead of eight on the twelve-movie panel. This experiment tests whether the pipeline's existing DeepCenter safe-division veto removes unsupported forks without sacrificing enough true divisions or edges to offset the precision gain.

This is a submission-valid controlled experiment. A candidate should be submitted only if official local metrics improve without a material node or edge regression.

## Result

Rejected. The veto scored `0.919201`, with adjusted edge Jaccard `0.914439`, division Jaccard `0.047619`, and division counts `1 TP / 3 FP / 17 FN`. It removed false positives but also eliminated three of four baseline true divisions and created three additional false negatives.

The existing veto is much too aggressive and must not be submitted. Future precision control should rank candidate forks and use calibrated acceptance thresholds instead of applying this hard rule.
