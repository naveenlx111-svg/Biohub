# E0030: ExtraTrees parent-event ranker

E0030 independently evaluates an ExtraTrees classifier on the same label-free geometry, raw-image, temporal, daughter, and DeepCenter features extracted by E0029. The tree ensemble uses embryo-held-out predictions and balanced sample weights.

This parallel run tests whether E0029's result is model-specific. It remains diagnostic and does not alter the tracking graph.

## Result

Rejected. It inherited E0029's unstable cross-run node-ID join and therefore evaluated only nine of 16 positives. Mean embryo-held-out average precision was `0.000145` and mean ROC AUC was `0.3866`. Every audited high-score threshold contained zero positive candidates.

The ExtraTrees model provides no evidence of generalizable parent-event discrimination. The next corrected audit must generate candidates, rank daughter pairs, and extract parent features from one inference graph in the same run.
