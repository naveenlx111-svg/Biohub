# E0020: corrected division localization audit

E0020 freezes all E0019 predictions, validation selection, and scoring configuration. The only change is reading matched prediction/GT pairs through tracksdata's declared attribute keys before calculating physical centroid distance.

Expected official metrics must reproduce E0019. Promotion is diagnostic: the run must produce nonempty parent/daughter localization distributions at 3 µm and 7 µm across the same 18 annotated division events.

## Results

Official metrics exactly reproduce E0019: adjusted edge Jaccard 0.914855, division Jaccard 0.153846, combined score 0.930240, and division counts 4 TP / 8 FP / 14 FN.

The tighter localization hypothesis is supported. Official 7 µm matching hides a large daughter and granddaughter localization gap between successful and missed divisions. Five of the fourteen missed events nevertheless have the parent and both daughters within 3 µm, showing that localization alone is not sufficient: fork topology remains a separate failure.

The next diagnostic should measure reparent/fork candidate recall and an oracle repair ceiling. A production ranker should combine local image localization confidence with parent-daughter distance, sister geometry, motion divergence, current-parent plausibility, and learned association confidence.
