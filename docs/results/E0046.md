# E0046: physical-neighborhood temporal-crop pooling

E0046 keeps E0041's embryo-held-out model but evaluates each detected parent at seven centers: the proposal center plus offsets of `±3.25 µm` independently along z, y, and x. It compares center score, maximum score, top-two mean, and all-offset mean on the complete candidate pool.

## Execution status

The first Kaggle run under a collaborator's account failed after saving the
production submission, all twelve validator prediction graphs, and the
preliminary `validator_results.csv`. It stopped before the patched official
score, fork construction, crop training, detected-candidate transfer, or any
offset score. The downloaded partial output therefore contains no evidence for
or against neighborhood pooling.

A local RTX 5060 run was then started twice. The first was intentionally
stopped at the user's request before meaningful work. The second was killed
externally during the initial four-movie inference pass when the NVIDIA device
became unavailable to `nvidia-smi`; the log ends mid-frame without a Python
traceback. No offset metrics were produced.

An authenticated Colab L4 runtime was subsequently provisioned. The full
competition archive passed its exact `87,393,127,165`-byte check and extracted
to the expected `24,886` files (`199` train images, `199` train graphs, and
`4` public-test images). Colab-specific preflight exposed and resolved two
launch faults before inference:

- the Kaggle offline wheel set does not contain the transitive `psygnal`
  dependency under Colab's Python 3.13, so the Colab setup now installs the
  complete runtime dependency set online;
- `/content/working` must exist before notebook initialization, otherwise the
  secondary checkpoint is materialized beside the inference repository and
  its relative child-process path fails.

Critical imports and both model checkpoints were verified, and a one-movie
smoke test reached model loading. Colab then reclaimed the runtime before the
corrected smoke test could enter inference. Immediate requests for A100, H100,
G4, L4, and T4 all returned HTTP 503 capacity errors. This is execution
evidence only; it provides no offset-quality result.

Status: interrupted by execution infrastructure; hypothesis remains untested.
