# E0038: calibrated linear track-context parent ranker

E0038 uses E0037's corrected 0.933 candidate pipeline and lineage-context features, then evaluates a standardized, regularized logistic classifier with embryo-held-out predictions.

The simpler model directly tests whether the tree models' cross-embryo probability shift is caused by overfitting. It is diagnostic and does not mutate the graph.

## Result

Rejected. The valid audit retained all 16 positives among 115,478 parents. Logistic regression achieved mean ROC AUC `0.6462` and mean average precision `0.000657`, both below E0037's `0.7747` and `0.000794`.

The loosest audited threshold retained five positives with 11,543 false candidates; thresholds with fewer than 1,000 accepted candidates retained no positives. A simpler calibrated model does not solve parent identification, so the next line should learn directly from temporal 3D crops rather than continue reweighting the same handcrafted features.
