# E0044: focal candidate-domain hard-negative fine-tuning

E0044 is the stricter parallel variant of E0043. It uses the same embryo-safe detector-proposal protocol with a larger top-hard-negative pool and focal loss to emphasize confusing false parent proposals.

Configuration: focal loss with gamma 2, 2,048 top hard negatives and 256 reservoir-sampled negatives per fold, 16 fine-tuning epochs, learning rate `1.5e-4`.

Status: completed and rejected. No graph mutation was performed.

## Result

The complete pool again contains 115,478 candidates and 16 positives. Focal
adaptation reached AP `0.002674` and ROC AUC `0.609756`. It produced `0 TP /
10 FP` globally at top ten and `0 TP / 60 FP` across top five per movie, with
no zero-FP true positive or useful embryo-transferred threshold.

E0044 is weaker than E0043 on AP and equally unusable at the precision head.
Hard-negative fine-tuning therefore does not justify integration into the
verified 0.933 graph.

The same promotion gate as E0043 applies: at least `5 TP / <=1 FP` for current top-five-scale evidence, `4 TP / <=1 FP` for a local-0.95 integration, or `2 TP / 0 FP` for a limited conservative probe. AP or ROC improvement without such a strict operating point is insufficient.
