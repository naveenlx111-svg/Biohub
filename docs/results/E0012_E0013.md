# E0012-E0013: learned edge-candidate threshold sweep

## Parent

Both arms use E0005/SDW75 with adjusted edge Jaccard 0.9159 and change only `BIOHUB_DUAL_SEED_EDGE_THRESHOLD`, whose parent value is 0.48.

## Arms

- E0012 lowers the threshold to 0.46, admitting more learned association candidates before constrained graph optimization.
- E0013 raises the threshold to 0.50, removing marginal learned candidates before optimization.

This differs from E0008/E0009: those runs changed evidence weights after logits were produced, whereas these arms change which candidate edges are available to the optimizer.

## Decision rule

Compare adjusted edge Jaccard, recovered/fragmented/lost-to-detection counts, and per-sample deltas against E0005. A lower threshold must recover enough true edges to offset extra false candidates; a higher threshold must remove errors without fragmenting valid tracks. Ignore the embedded obsolete division proxy for promotion.
