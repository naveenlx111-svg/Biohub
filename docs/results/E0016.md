# E0016: patched official metric audit

E0016 freezes the E0005/SDW75 production pipeline and changes only validation. It scores the exact postprocessed held-out graphs with the patched official `tracking_cellmot` implementation rather than the notebook's hand-written division proxy.

The notebook refuses to report results unless `metrics.py` and `division_metrics.py` match the published reference hashes for commit `075fc5f`. It records per-volume edge and division TP/FP/FN, the correctly weighted adjusted edge Jaccard, the micro-averaged division Jaccard, and the combined score.

The legacy proxy is retained solely to report count discrepancies. No model or postprocessing parameter changes in this experiment, and its production `submission.csv` is not a promotion candidate.

The reference scorer reproduces E0005's adjusted edge result but reveals substantial division headroom: four of five annotated divisions are missed. Raising division Jaccard from 0.1667 to 0.4 would add about 0.0233 to the combined validation score without requiring an edge gain, which is large enough to cover the current leaderboard gap in principle.

The next experiment should preserve the validation graphs and evaluate division-repair variants against the official scorer in one paired run. It must distinguish missing daughter detections from lineage-topology failures before choosing a production change.
