# E0010-E0011: detector recall sweep on SDW75

## Parent

Both experiments use E0005/SDW75, the current internal-validation leader at adjusted edge Jaccard 0.9159.

## E0010: secondary detection weight 0.80

Change only `BIOHUB_SECONDARY_DETECTION_WEIGHT` from 0.75 to 0.80. The progression from 0.70 to 0.75 improved validation by 0.0003, so this arm tests whether the curve continues or has passed its optimum.

## E0011: detector threshold 0.965

Change only `BIOHUB_DET_THRESHOLD` from 0.96875 to 0.965, including the configuration guard. This admits a modest number of additional cell candidates. The node adjustment makes extra detections relatively cheap, but the arm succeeds only if added candidates recover more annotated edges than they fragment.

## Decision rule

Compare weighted adjusted edge Jaccard with 0.9159 and inspect missed GT nodes, recovered edges, fragmentation, predicted-node counts, and per-sample deltas. Ignore the obsolete embedded division proxy when deciding promotion.
