# E0021: midpoint division ranker

E0021 is a production-changing experiment on the expanded 12-movie validator. It targets detected daughters currently assigned to another single-child track and proposes a fork only when the daughter pair is temporally valid, close to the parent, symmetric around the parent, continues into two branches, and diverges in the following frame.

Candidates are ranked by midpoint consistency, sister distance, radial balance, motion consistency, and outward divergence. Selection is non-conflicting, limited to one repair per frame, and globally capped. Reparenting removes the displaced incoming edge so each daughter retains one parent.

Promotion requires combined official score above E0020's 0.930240, with a division gain that exceeds any adjusted-edge loss. The generated production submission must not be submitted before validation results are reviewed.

## Results

| Metric | E0020 | E0021 | Delta |
| --- | ---: | ---: | ---: |
| Adjusted edge Jaccard | 0.914855 | 0.913505 | -0.001351 |
| Division Jaccard | 0.153846 | 0.114286 | -0.039560 |
| Combined score | 0.930240 | 0.924933 | -0.005307 |
| Division TP / FP / FN | 4 / 8 / 14 | 4 / 17 / 14 | 0 / +9 / 0 |

The ranker created additional forks but none corresponded to an annotated division. It also removed several correct continuation edges. All thirteen detection-complete division misses still lack a valid parent-side fork.

Geometry, motion continuity, and divergence are therefore insufficient discriminators for reparenting. The next ranker must include learned association logits or local image evidence and must first demonstrate that true fork edges occur in its candidate set before any production mutation is enabled.
