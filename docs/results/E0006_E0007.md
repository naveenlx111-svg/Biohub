# E0006-E0007: association and selective-recall arms

## Context

The team-provided SDW70 notebook is executable-code identical to the public SDW70 source and scored 0.928 for the team. Detector fusion therefore improved the verified 0.927 anchor by only 0.001; the public 0.934 label did not transfer.

E0006 and E0007 freeze SDW70's detector fusion weight at 0.70 and target separate error mechanisms. They are prepared locally and queued because Kaggle currently has two active GPU sessions running E0004 and E0005.

## E0006: stronger velocity consistency

Change only `BIOHUB_MOTION_RELINK_VELOCITY_WEIGHT` from its default 0.5 to 1.0. Motion relinking predicts continuation position from the preceding displacement. A larger weight should help at close crossings if constant-velocity evidence is reliable, but can hurt accelerating or dividing cells; validation must be checked per sample.

## E0007: selective short-track rescue

E0003 showed that retaining every short component is harmful, but it also reduced missed annotated nodes from 40 to 22 and recovered eight additional GT edges. E0007 keeps the length-six filter and activates its existing bounded rescue gate. The gate considers only components of length four or five, requires mean edge confidence at least 0.82 and mean physical edge distance at most 3.25 micrometres, and caps restored nodes by both fraction and absolute count.

This directly tests whether the useful recall from E0003 can be retained without its full node and fragmentation cost.

## Promotion order

1. Finish E0004/E0005 and choose the better detection weight.
2. Launch E0006 and E0007 when GPU slots free.
3. Promote only improvements in weighted adjusted edge Jaccard with acceptable per-sample consistency.
4. Rebuild the winning arm on the selected detector weight if 0.75 beats 0.70.

## Results

E0004's SDW70 validation anchor was adjusted edge Jaccard 0.9156.

- E0006 returned **0.9125**, a **-0.0031** change. It recovered 2,184 annotated edges versus 2,187 for E0004 and increased fragmented edges from 63 to 66. Stronger constant-velocity weighting is rejected.
- E0007 returned **0.9156**, an exact aggregate and per-sample tie with E0004. The rescue gate did not alter the four validation graphs, but it changed the production output from 121,302 nodes / 117,036 edges to 121,480 nodes / 117,172 edges. With no measured validation gain, this is not promoted.

The notebooks' division values remain obsolete proxies and were not used in these decisions.
