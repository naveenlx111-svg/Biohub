# E0017: division failure anatomy

E0017 freezes SDW75 and uses the patched official scorer to classify each annotated validation division. Misses are separated into absent parent/daughter detection evidence, detections present without a parent-side fork, incorrect fork branch topology, and scorer pairing conflicts.

The run also exports the safe-division candidate and DeepCenter funnel for each validation volume. This is a diagnostic experiment and does not produce a promotion candidate. Its result selects the first division-repair implementation rather than another scalar sweep.
