# E0017: division failure anatomy

E0017 freezes SDW75 and uses the patched official scorer to classify each annotated validation division. Misses are separated into absent parent/daughter detection evidence, detections present without a parent-side fork, incorrect fork branch topology, and scorer pairing conflicts.

The run also exports the safe-division candidate and DeepCenter funnel for each validation volume. This is a diagnostic experiment and does not produce a promotion candidate. Its result selects the first division-repair implementation rather than another scalar sweep.

## Results

Five annotated validation divisions were inspected. The existing true positive has two parent-evidence nodes, both daughter lineages represented, and one strong parent-side fork. Each of the four false negatives also has two parent-evidence nodes and both daughter lineages represented, but has zero parent-side forks.

| Failure class | Count |
| --- | ---: |
| True positive | 1 |
| Detections present but parent fork absent | 4 |
| Missing parent or daughter evidence | 0 |
| Fork present but branch topology wrong | 0 |

The missed divisions are therefore association failures rather than detection failures. The current safe-division repair only considers orphan second daughters, so it cannot recover a daughter that was detected but linked into another track. The next production-changing experiment should add a tightly gated division-aware reparenting proposal and evaluate its edge cost and division benefit together with the official scorer.
