# E0019: expanded division localization audit

E0019 freezes SDW75 and expands the division-rich validator from four to twelve full movies. It uses the hash-verified patched official scorer and reports division parent, daughter, and granddaughter localization at both 3 µm and the official 7 µm matching gate.

This tests the recent forum hypothesis that high global 7 µm node recall can conceal materially worse localization around mitosis. It also expands the E0017 failure-anatomy sample before a learned division ranker is designed.

Primary outputs are `official_validator_results.csv`, `division_failure_anatomy.csv`, `division_localization_rows.csv`, and `division_localization_summary.csv`. This is a diagnostic run; its submission is not a promotion candidate.
