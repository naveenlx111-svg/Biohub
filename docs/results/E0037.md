# E0037: track-context parent ranker

E0037 extends E0035's corrected 0.933 parent-event pipeline with label-free lineage context: parent history span, both daughters' future track spans and asymmetry, and parent incoming speed. These features test whether persistent pre- and post-division tracks can separate real divisions from geometrically plausible neighboring cells.

The experiment uses embryo-held-out predictions and does not mutate the graph. It is a submission precursor, not a submission notebook.

## Result

Track context improved ranking but did not produce an integrable operating point. All 16 positive parents survived among 115,478 candidates. Mean ROC AUC increased from E0035's `0.7421` to `0.7747`, and mean average precision increased from `0.000694` to `0.000794`.

Absolute calibration remained embryo-dependent. The best audited global threshold retained two positives with 6,169 false candidates. Movie-relative ranking also failed: top 20 per movie recovered one positive with 239 false candidates, top 50 recovered three with 597 false candidates, and top 100 recovered four with 1,196 false candidates.

The added lineage features contain real ranking information but are insufficient for graph mutation. E0038 tests whether a regularized linear model can generalize their calibration better.
