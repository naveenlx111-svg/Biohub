# E0023: official 12-movie audit of the 0.931 anchor

E0023 freezes the leaderboard-verified 0.931 division-wide configuration and expands its validator to twelve division-rich full movies. It adds the hash-verified patched official scorer, failure anatomy, and corrected 3 µm versus 7 µm division localization.

This run is independent of E0022 and can execute concurrently. It establishes the correct local baseline for future production changes because the previous structural diagnostics used SDW75 rather than the current leaderboard anchor.

## Result

The 0.931 leaderboard anchor scored `0.926608` on the twelve-movie local panel: adjusted edge Jaccard `0.914108`, division Jaccard `0.125000`, and division counts `4 TP / 14 FP / 14 FN`. Raw edge Jaccard was `0.909251` and node recall was `0.981668`.

Of the 14 missed divisions, 12 had complete parent-and-daughter detection evidence but no parent-side predicted fork; two lacked required evidence. Missed-daughter recall was `0.893` within 7 µm but only `0.571` within 3 µm. This again identifies division association as the main recoverable error, while also showing that this small local panel does not reproduce leaderboard ordering precisely: the verified 0.931 anchor scores lower locally than SDW75.

The anchor creates the same four local division true positives as SDW75 but six additional false positives. E0025 therefore tests the pipeline's existing conservative division veto as a controlled, submission-valid precision change.
