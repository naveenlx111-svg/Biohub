# E0036: ExtraTrees parent ranker on the 0.933 anchor

E0036 shares E0035's corrected scorer-namespace candidate, pair-ranking, and parent-feature pipeline, then evaluates an independent ExtraTrees parent-event classifier with embryo-held-out predictions.

This parallel model check is structurally valid only if all positive candidate triples survive feature extraction. It is diagnostic and does not mutate the graph.

## Result

Rejected. The corrected pipeline retained all 16 positive parent candidates among 115,478 parents, so the comparison is structurally valid. ExtraTrees achieved mean ROC AUC `0.6654` and mean average precision `0.000255`, both below E0035's `0.7421` and `0.000694`.

At the loosest audited threshold it retained one positive with 11,547 false candidates; all stricter thresholds retained zero positives. E0035 remains the stronger model, although neither supports graph integration.
