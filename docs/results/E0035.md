# E0035: corrected parent ranker on the 0.933 anchor

E0035 combines the verified 0.933 production configuration with E0027's wide label-free fork proposals and the corrected scorer-namespace parent feature lookup. Candidate generation, embryo-held-out daughter-pair ranking, image and DeepCenter feature extraction, and parent-event classification occur within one inference run.

The run is accepted as structurally valid only if all 16 positive candidate triples survive into the parent-event audit. It is diagnostic and does not mutate the submission graph.

## Result

Structurally valid but not integration-ready. The wide proposer generated 493,834 candidates, 18 positive triples, and proposed 11 of 18 annotated divisions. Conditional proposal recall was `0.7857` among the 14 divisions with matched role triples.

After embryo-held-out pair selection, all 16 positive parent candidates survived among 115,478 proposed parents. The parent classifier achieved mean ROC AUC `0.7421` and mean average precision `0.000694`, a clear ranking improvement over E0029. However, calibration shifted severely between embryos: positive scores were near `0.31` for held-out 44b6 but near zero for held-out 6bba.

No global threshold is usable. The best audited operating points retained at most two positives with more than 6,000 false candidates; stricter thresholds retained no positives. E0035 should not mutate graphs, but its valid out-of-fold output supports testing embryo- or movie-relative ranking and calibration.
