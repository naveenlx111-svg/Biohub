# E0004-E0005: secondary detection fusion sweep

## Motivation

The verified SDW60 anchor scored 0.927 with `BIOHUB_SECONDARY_DETECTION_WEIGHT=0.60`. A newly published SDW70 notebook reports 0.934. Normalized source comparison shows exactly one code change between SDW60 and SDW70: the secondary detection fusion weight rises from 0.60 to 0.70.

This is a detection-field mixture, not an association-logit weight. It can change candidate recall and localization before graph construction, giving it more headroom than the small harmonic association ablations.

## Arms

- E0004: secondary detection weight 0.70; otherwise byte-equivalent executable code to SDW60.
- E0005: secondary detection weight 0.75; neighboring arm from the same public source lineage.

Both run the full production test path and the embedded held-out validator. They are private Kaggle kernels with internet disabled and the same three model/data artifacts as SDW60.

## Decision rule

Use adjusted edge Jaccard and per-sample behavior to choose between 0.70 and 0.75. Treat the embedded division result as unofficial until rescored with the patched scorer. Submit E0004 first if its output is valid because 0.70 already has an independently reported 0.934 public result; submit E0005 only if its validation evidence is stronger.

## Next structural step

After choosing the detector-fusion weight, freeze detections and target association errors separately. The leading candidate is a confidence-gated velocity residual applied only to low-margin continuation choices, avoiding changes to already high-confidence links.
